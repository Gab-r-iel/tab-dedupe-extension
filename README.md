# Tab 去重助手

一个无需构建、可直接加载到 Chrome 的 Manifest V3 扩展。当同一网页已经打开时，扩展会切换到最早打开的原标签页，并关闭刚打开的重复标签页。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`outputs/tab-dedupe-extension`。

安装后，Chrome 工具栏会出现扩展图标。如果没有显示，可在扩展菜单中将它固定到工具栏。

## 默认行为

- 只处理 `http://` 和 `https://` 页面。
- 默认忽略网址末尾的 `#锚点`，但保留查询参数差异。
- `?q=one` 和 `?q=two` 会视为不同页面。
- 默认保护置顶标签页，不关闭它们，也不将它们当作原页面。
- 重定向完成后再次判断，因此短链接跳转后的最终页面也能去重。
- 设置和数据只保存在 Chrome 本地，不会上传。

## 使用

- 点击工具栏图标可暂停或重新开启自动去重。
- 点击“在本站允许多开”可为当前网站添加例外。
- 点击“设置忽略规则和策略”可维护网址规则、置顶标签页策略和放行名单。

忽略规则示例：

```text
example.com
mail.example.com/inbox*
*://*.internal.example.com/*
```

## 权限说明

- `tabs`：读取标签页地址，并切换或关闭重复标签页。
- `webNavigation`：在页面完成导航时判断是否与新标签页重复。
- `storage`：在本地保存开关、忽略规则和统计。

## 开发与验证

核心 URL 判断逻辑位于 `common.js`，单元测试位于 `tests/core.test.js`。

```bash
node --test tests/core.test.js
```
